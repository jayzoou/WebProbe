# 功能实现

读取 AGENTS.md、相关产品/架构事实和受影响代码。使用现有任务规格；需求有歧义时先识别会改变用户结果的关键假设。简单修改不强制生成任务文档，复杂工作使用 tasks/TASK_TEMPLATE.md 明确验收和风险。

沿用现有边界，实现授权范围内的完整用户链路。按场景处理加载、空、失败、取消和并发；新依赖或公共接口变更说明必要性及兼容性。

按 docs/testing-strategy.md 选择能发现回归的验证，不为文案机械添加测试。按 docs/quality-gates.md 选择风险并运行真实门禁。失败则定位修复；环境阻塞时保留失败事实，不能降低门禁或虚构结果。

交付前审查差异，必要时进行浏览器验收。使用 tasks/COMPLETION_TEMPLATE.md 记录变更、实际命令、runId、验收映射和限制。自动化通过不等于任务已由人工验收。
