# V1.0 验证记录

验证日期：2026-11-25。环境：macOS Apple Silicon、Node.js 22.22.2，依赖版本以 `package-lock.json` 为准。

- `npm run build`：前后端 TypeScript 检查和 Vite 生产构建通过。
- `npm test`：8 项核心测试通过，覆盖输入校验、地址限制、HTTP/CONNECT 出口代理、Issue 聚合与复发、未覆盖检查不误判修复、质量准入、API、导出和规则诊断。
- `npm run test:e2e`：完整通过。使用独立临时数据目录和本地已知缺陷页面，验证 Chromium、Firefox、WebKit，2 个页面的站内发现、真实 Lighthouse 报告、异常/布局/无障碍检测。
- 上述固定测试中首次发现 42 条跨页面/浏览器的问题；修复测试页面后，同配置检测确认 42 条不再出现并更新 Issue 状态。此数字只描述该测试样例，不代表一般网站检出能力。
- 单独验证 Chromium 移动视口检测、含截图和原始报告的 ZIP 修复任务包、问题详情与规则建议、移动导航、页面无横向溢出、无前端 `pageerror`。
- 依赖安装后的 npm 安全审计：0 个已知漏洞。

实际截图输出到本地 `test-results/`，不提交到源码。测试数据不会写入默认用户 `data/`。

尚未使用用户真实模型凭证进行外部 AI 服务联调；当前验证了规则降级，模型接入具有请求超时和输出 Schema 校验。尚未对所有公网网站、操作系统、真机或业务流程作兼容性保证。
