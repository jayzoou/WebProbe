# WebProbe · 测试与证据

## 分层验证

- 静态：Prettier 格式，以及前后端 strict TypeScript。当前无独立 ESLint 配置。
- 核心：Node test + tsx，覆盖 Schema、问题聚合、覆盖不足不误判修复、质量准入、API、导出和规则诊断。
- 安全：独立 security.test.ts，保留已有地址与代理测试，并覆盖云元数据、Host/Origin/Token 和代理写操作边界。不做真实内网或公网探测。
- E2E：已有 tests/e2e.ts，运行真实三浏览器、Lighthouse、受控缺陷页、修复回归、移动视口和 ZIP 导出。

测试不加载用户 .env；测试进程清除模型凭证与 API Token，测试需要的 Token 使用固定隔离值。SQLite 和扫描证据写入临时数据目录，不写入用户 data。E2E 为受控本地页面显式启用内网，安全测试独立进程保持默认禁止私网。

## 选择测试

简单文案/样式无需机械新增单测；复杂状态、取消、异步竞态、边界和历史缺陷需要可观察行为测试。修改网络防护或扫描引擎时必须执行 high，保留安全门禁与真实浏览器证据。

报告区分实际命令和未执行项，不以测试数量代替覆盖质量。模型真实联调、真机、所有公网网站兼容性和生产隔离均不能由现有 E2E 推导为通过。

原有 V1.0 验证历史保留在 docs/validation.md；本次运行的实际结果以 `.ai-workflow/reports/<runId>/` 为准。

## V2 增量覆盖

`tests/testing.test.ts` 验证受限步骤、显式断言、用例版本、脚本导出转义、功能 Issue 边界与像素/基线隔离。`tests/testing-e2e.ts` 在 V1 E2E 后执行，使用第二个独立服务端口 4189 与受控交互页面：真实三引擎缺陷/修复、模型隔离桩、探索重放、操作录制与敏感输入省略、基线审批与视觉差异、请求权限、取消和移动端界面。禁止使用真实付费模型凭证；桩联调不代表已验证某个外部模型供应商。
