# 交付记录：任务标题

- 关联任务与版本：
- 实现结果：用户可观察到的变化，以及相关文件
- 设计取舍：影响维护、兼容和安全的必要说明

| 验收条件 | 实际执行的命令或操作 | 结果                 | 证据                |
| -------- | -------------------- | -------------------- | ------------------- |
| AC-1     | 填写已执行项         | 通过 / 失败 / 未执行 | runId、日志、截图等 |

- 自动化报告：`.ai-workflow/reports/<runId>/report.md`
- 浏览器与人工验收：环境、操作、实际结果、验收人；未执行写明原因
- 已知限制与未验证项：具体范围、影响、后续处理
- 发布/回滚：仅在涉及部署或数据变更时填写

不要把建议执行的命令列为已执行，不把自动化通过当作人工验收完成。
